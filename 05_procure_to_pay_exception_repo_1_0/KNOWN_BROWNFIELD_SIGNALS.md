# Known Brownfield Signals
This file is intentionally non-exhaustive.

Look for:
- contradictions between policy and implementation
- inconsistent identifiers or thresholds
- unsafe fallback logic
- missing ownership / approval
- weak evidence lineage
- human override without traceability
- unvalidated or weakly evaluated AI components
- audit gaps
- security / access concerns
- missing observability
- incomplete failure testing
- deployment / rollback weaknesses

There may be additional issues not listed here.
