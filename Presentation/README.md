# Presentation pack

This folder is the team walkthrough for use case 5, Procure-to-Pay Exception and Payment Control.

A teammate presents from `Team_Presentation.pptx`. The notes pane on each slide is the speaking script. `SLIDE_OUTLINE.md` is the same seven slides in text. `DEFENCE.md` answers the nine questions. The teammate does not need Cursor open.

## Four deliverable folders

| Folder | What it is |
|---|---|
| `D1_AsIs_Assessment/` | The reading of inherited Repo 1.0. Conflicts, missing controls, and the replay of INV-1001 through INV-1004 and CH-88. |
| `Repo_2_0/` | The To-Be design. One file for each of the ten runbook steps. |
| `D3_PRD/` | The product requirements document, version D3a, and the trace from design to requirements. |
| `D4_App/` | The working payment-control app, the click script, and the 22 Sep 2026 test notes. |

Repo 1.0 stays in `05_procure_to_pay_exception_repo_1_0`. This presentation does not edit that folder.
