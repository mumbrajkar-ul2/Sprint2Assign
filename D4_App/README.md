# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

How the running app implements the ten Sprint 2 spine steps is in [Documentation/SPINE_IMPLEMENTATION.md](Documentation/SPINE_IMPLEMENTATION.md).

View your app in AI Studio: https://ai.studio/apps/4d381f01-eadc-4c67-bc79-5a3f55eb5e53

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
